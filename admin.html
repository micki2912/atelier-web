Gérer le portfolio

Les projets sont stockés dans un Google Sheet. Ouvrez-le pour ajouter, modifier ou supprimer des projets — le site se met à jour automatiquement.

Ouvrir Google Sheets Voir le site public

Structure des colonnes

Votre Google Sheet doit avoir ces colonnes en première ligne :

ColonneDescription
titre *Nom du projet (ex : Site vitrine — Cave Dupont)
client *Nom du client
categorieType : Site vitrine, E-commerce, SEO, Refonte…
descriptionTexte court décrivant le projet (2–3 phrases)
urlLien vers le site réalisé (https://…)
image_urlLien https://… ou chemin local : images/monprojet.jpg

Configuration initiale

Première utilisation ? Suivez ces étapes :

Créez un Google Sheet avec les colonnes ci-dessus en première ligne.
Dans le Sheet : Fichier → Partager → Publier sur le web → choisissez Feuille 1 et format CSV → cliquez Publier.
Copiez l'URL obtenue et collez-la dans js/supabase-config.js à la ligne SHEET_CSV_URL.
Mettez également à jour la constante SHEET_EDIT_URL ci-dessous avec le lien d'édition de votre Sheet (pour que le bouton "Ouvrir" fonctionne).
